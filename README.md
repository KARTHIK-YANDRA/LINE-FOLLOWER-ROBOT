# Autonomous Line Follower Robot

## Description
Developed a sensor-based autonomous line follower robot using Arduino and embedded control techniques.

## Features
- Real-time line tracking
- Sensor-based navigation
- Motor control logic
- Direction correction mechanism

## Components Used
- Arduino UNO
- IR Sensors
- DC Motors
- Motor Driver

## Tools Used
- Arduino IDE
- Embedded C++

## Project Files
- line_follower.ino
